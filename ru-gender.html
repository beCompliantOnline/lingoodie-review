Russian noun gender — for review

Every Russian noun that didn't already have a gender note (75) with a proposed masculine / feminine / neuter, from the word ending plus hand-fixes for the tricky ones — animates (папа, дедушка = masculine), soft-sign nouns (площадь, бронь, дочь = fem; отель, учитель = masc), -мя neuters (имя), indeclinables (радио, метро, пальто = neuter; кофе = masculine). Non-nouns (verbs, adjectives, adverbs, numbers, pronouns) were left alone. Skim each group — a wrong-gender word stands out. Note fixes in the box under each group, then Download comments → send me.
